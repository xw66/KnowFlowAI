# 前端重写方案

目标：围绕知识库完成收集文档、查找资料、基于证据问答和权限管理，替换旧版堆叠表单。

参考：https://ima.qq.com/ 的知识库与问答历史导航；https://gitbook.com/docs/publishing-documentation/search-and-gitbook-assistant 的检索、问答及可展开来源。只参考信息组织，不复制品牌或不存在的后端能力。

布局：左侧固定知识库列表；右侧当前知识库标题与文档、问答、设置导航。移动端导航自动收拢。白色 #ffffff、侧栏 #f7f8fa、边框 #e5e7eb、正文 #20242c、次要文字 #667085、强调蓝 #335cff。字体采用系统中文无衬线；正文左对齐，问答阅读区限制宽度。去掉广告标题、无意义统计和常驻高级参数。

组件职责：App 只管理登录态；LoginPanel 登录注册；Workspace 管理知识库与导航；DocumentsPane 管理列表、上传和后台状态；AssistantPane 管理搜索、历史和续问；MembersPane 管理授权与改名；SourceList 展示服务端引用。功能组件接收 api 与 base，变更通过事件向上通知。切换知识库/页面卸载子组件并取消请求，禁止旧响应写入新页面。

业务约束：401 统一退出；VIEWER 不显示写操作，只有 OWNER 显示成员管理；所有请求显示可见错误。上传保留幂等键供重试，不同步等待解析；自动刷新进行中状态。搜索与问答使用当前知识库；会话加载后提交真实 conversationId 续问。流式回答只有 done 才完成，error.discard 清除证据，取消或断流保留未完成标记。原文只显示服务端返回的内容。

验收：TypeScript 与生产构建；Node 原生测试覆盖 SSE 分帧、错误、断流、取消及 API 错误；浏览器验证登录、创建/切换知识库、权限界面、文档空状态、搜索和历史界面；记录真实联调与协议替身的区别。
